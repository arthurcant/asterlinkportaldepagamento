# Banco de dados MySQL

Execute os scripts `001` a `008` nessa ordem. O terceiro cria o acesso `teste` / `teste`; o quarto cria o catálogo atual de planos; o quinto registra as sessões liberadas após pagamentos aprovados; o sexto cria os pedidos de acesso; o sétimo adiciona o CPF aos usuários de bancos já existentes; e o oitavo adiciona a velocidade comercial e atualiza o catálogo de um banco existente. Ajuste `ConnectionStrings:DefaultConnection` no `appsettings.json` ou use a variável `ConnectionStrings__DefaultConnection`.
