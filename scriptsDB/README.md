# Banco de dados MySQL

Execute os scripts `001` a `005` nessa ordem. O terceiro cria o acesso `teste` / `teste`; o quarto cria os planos de 1h/R$ 5, 2h/R$ 10 e 3h/R$ 15; o quinto registra as sessões liberadas após pagamentos aprovados. Ajuste `ConnectionStrings:DefaultConnection` no `appsettings.json` ou use a variável `ConnectionStrings__DefaultConnection`.
